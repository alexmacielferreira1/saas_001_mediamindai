AI Edita - original synthesized sound effects
Generated by scripts/sound-library/palettes.py, the same synthesis engine as the
built-in sound library (scripts/sound-library/dsp.py), with a fixed seed.
No third-party recordings. Licensed under the same license as this repository.
48 kHz mono PCM WAV.

Theme palettes (classic, paper, punch, soft, digital) plus the default set at the
root of this folder, used when a recipe asks for a sound without naming a palette.
Each palette has hit, pop, whoosh and riser, calibrated by measured RMS:
hit -22 dB, pop -23 dB, whoosh -24 dB, riser -26 dB. Whoosh and riser are high-passed
at 1.2 kHz so they are not masked by speech. Used at 0 dB by the theme planner.

Regenerate with:
  python scripts/sound-library/palettes.py
