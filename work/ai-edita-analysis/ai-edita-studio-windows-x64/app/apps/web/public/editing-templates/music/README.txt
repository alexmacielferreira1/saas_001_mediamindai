AI Edita - theme music beds
Original instrumental loops synthesized in code (oscillators and envelopes, no samples):
sobria (90 BPM dark corporate), lofi (84 BPM rhodes), energia (124 BPM four-on-the-floor),
ambient (70 BPM pads and bells), synth (108 BPM synthwave). 125 s each, MP3 192 kbps,
loudness-normalized to -20 LUFS. The theme recipe sets bed and end-card gain in dB.
