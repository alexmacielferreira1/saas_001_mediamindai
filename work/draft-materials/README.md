# Materiais para rascunhos e Copiloto

Área provisória e local do MediaMind para receber referências, textos e outros materiais que possam virar rascunhos.

- `entrada/`: coloque aqui os arquivos novos para revisão.
- `organizados/`: cópias preservadas e separadas por assunto/tipo depois da revisão.
- `rascunhos-copiloto/`: resumos, ideias de rascunho e sugestões do Copiloto derivados dos materiais revisados, sempre com referência ao arquivo de origem.

Rotina de revisão: conferir novos arquivos em `entrada/`; preservar os originais; organizar cópias sem sobrescrever conteúdo; registrar duplicatas ou arquivos ilegíveis sem apagá-los; e preparar em `rascunhos-copiloto/` somente conteúdo útil, com título, resumo, formato sugerido e referência. Materiais sem contexto suficiente ficam pendentes, não são tratados como fatos nem publicados.

Esta pasta não é o fluxo de Produção nem o acervo do MediaMind. Nada daqui deve ser enviado automaticamente ao Copiloto, a um provedor de IA, a uma publicação ou aos rascunhos persistidos do sistema. A integração com essas áreas só acontece quando for implementada e explicitamente acionada.

Os arquivos depositados nesta área são ignorados pelo Git para evitar versionar mídia, documentos privados ou arquivos grandes. O README e a estrutura vazia permanecem versionados.
