# Avisos de terceiros

O MediaMind usa projetos de código aberto como referência de comportamento. Quando houver aproveitamento de código ou de parte substancial dele, a licença original é preservada aqui.

## Apps "Craft" — storytold (Apache License 2.0)

As Ferramentas Gráficas do MediaMind (MMFilm, MMEffects, MMVector, MMPhoto, MMLight, MMPDF, MMDesign, MMSom, MMFig, Word, Excel e PowerPoint) foram inspiradas nos aplicativos de código aberto da organização storytold: filmcraft, effectcraft, vectorcraft, photocraft, lightcraft, pdfcraft, designcraft, soundcraft, figcraft, wordcraft, gridcraft e deckcraft (https://github.com/storytold).

Esses projetos são aplicativos desktop escritos em Rust e licenciados sob a Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0). O MediaMind roda no navegador: o comportamento das ferramentas foi reimplementado em JavaScript/React pelo próprio MediaMind, e nenhum arquivo daqueles projetos foi copiado para este repositório.
