# Workspace 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Disponibilizar `/workspace2` com Pesquisa, Roteiro e Timeline integrados sem modificar `/workspace`.

**Architecture:** Uma página contêiner mantém o estado compartilhado e renderiza três etapas isoladas. Operações puras ficam em `workspace2Model.js`; componentes visuais consomem callbacks, permitindo testes sem backend e conexão persistente posterior.

**Tech Stack:** React 18, React Router, Tailwind CSS, lucide-react, Vitest e Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-21-workspace2-design.md`

## Global Constraints

- `/workspace` não pode ser alterado ou redirecionado.
- A nova rota é `/workspace2` e usa a permissão existente do módulo Workspace.
- As três imagens fornecidas são a referência visual.
- Ações sem backend não podem informar persistência concluída.
- Seleção, roteiro e timeline sobrevivem à troca de etapa.

## Review Focus

- Seleção duplicada: não criar duas cópias da mesma mídia.
- Seleção vazia: Roteiro e Timeline devem exibir estado vazio útil.
- Mídia removida: remover da seleção sem apagar blocos já adicionados ao roteiro.
- Troca repetida de etapa: não reinicializar estado.
- Rota antiga: `/workspace` continua apontando para `Workspace.jsx`.
